# TaskMaster Pro - Frontend App

This directory contains the React-based frontend application for **TaskMaster Pro**.

For complete documentation, project details, architecture diagrams, and docker setup instruction, please refer to the main **[README.md](../README.md)** at the root of the repository.

---

## ⚡ Quick Start

1. Install all dependencies:
   ```bash
   npm install
   ```
2. Run the local development server:
   ```bash
   npm start
   ```
3. Run the unit tests:
   ```bash
   npm test
   ```
4. Build the application for production:
   ```bash
   npm run build
   ```
